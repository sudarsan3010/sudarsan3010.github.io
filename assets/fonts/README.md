# Fonts

Self-hosted (no Google Fonts requests, which is faster and more private). All three families are free under the SIL Open Font License 1.1:

- **Schibsted Grotesk** (headings), by Schibsted Media Group
- **Instrument Sans** (body), by Instrument
- **JetBrains Mono** (labels), by JetBrains

Files are the Latin subsets from [Fontsource](https://fontsource.org).
