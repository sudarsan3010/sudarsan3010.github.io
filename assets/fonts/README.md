# Fonts

Self-hosted (no Google Fonts requests — faster and more private). All three families are free under the SIL Open Font License 1.1:

- **Schibsted Grotesk** (headings) — Schibsted Media Group
- **Instrument Sans** (body) — Instrument
- **JetBrains Mono** (labels) — JetBrains

Files are the Latin subsets from [Fontsource](https://fontsource.org).
